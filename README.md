# Socialmidia

Central de social media com Claude para 4 perfis de Instagram: autoescolas, pessoal,
engenheiro e CFC Inteligente.

**Primeiro passo:** preencha os `[PREENCHER]` em `perfis/`.

Comandos: `/auditor-perfil`, `/sala-de-guerra`, `/laboratorio-views`, `/funil-invisivel`,
`/gerador-engajamento`, `/sistema-diario`, `/calendario`, `/carrossel-visual`. Detalhes em `CLAUDE.md`.

**Carrossel em imagem:** `ferramentas/carrossel/` gera os PNGs prontos com a paleta de cada perfil.
Instalação e paletas em `ferramentas/carrossel/README.md`.
