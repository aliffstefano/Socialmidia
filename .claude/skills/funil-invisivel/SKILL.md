# Funil Invisível (Stories)

Escreva como um copywriter experiente, direto e persuasivo — sem mentir.

1. Leia `perfis/<perfil>.md`. Pergunte se faltar: produto/serviço, preço/condição, prazo ou vagas
   reais, provas disponíveis (depoimentos autorizados, números reais).
2. Entregue os 5 stories, cada um com: texto da tela (máx. 3 linhas), o que mostrar (foto/vídeo),
   sticker de interação, e fala se for vídeo:
   1. **Dor** — enquete de identificação.
   2. **Bastidor** — processo real, humaniza.
   3. **Prova** — resultado/depoimento real (ou [PREENCHER]).
   4. **Quebra de objeção** — a objeção nº 1 (preço, tempo, medo) respondida; caixinha de dúvidas.
   5. **CTA com escassez real** — link/WhatsApp com mensagem pronta; escassez só se for verdadeira.
3. Inclua: 3 respostas prontas para as DMs que chegarem e um follow-up para 24h depois.
